### File and Directory Descriptions

| File or Directory | Description |
|---|---|
| `main.py` | Main application file containing the primary program logic. |
| `hand_traking.py` | Implements hand tracking and related hand landmark processing. |
| `voice_engine.py` | Contains voice-related functionality, depending on its implementation. |
| `face_landmarker.task` | Pretrained MediaPipe model asset for face landmark detection. |

| `requirements.txt` | Lists the Python packages required to run the project. |
| `README.md` | Provides project information, setup instructions, and usage documentation. |
| `__pycache__/` | Automatically generated Python bytecode cache; normally excluded from version control. |

### Technology Stack

- **Python** — Core application development.
- **OpenCV** — Camera access and image/video processing.
- **MediaPipe** — Face and hand landmark detection.
- **Voice processing** — Implemented through `voice_engine.py`; the specific capabilities depend on the code.
- **NumPy** — Numerical operations, if used by the application.

### Model Assets

The project includes two MediaPipe model files:

- `face_landmarker.task` — Used for face landmark detection.
- `hand_landmarker.task` — Used for hand landmark detection.

Keep these files in the locations expected by your Python code, or update the model paths if you move them.

### Running the Project

Run the main application from the project directory:

```bash
python main.py
```

This assumes `main.py` is the intended entry point and that the required dependencies and model files are installed and available.

### Development Notes

- Keep model paths consistent with the paths configured in your Python files.
- Store dependencies in `requirements.txt` so the environment can be recreated.
- Consider excluding `__pycache__/` and `.pyc` files from Git using a `.gitignore` file.
- Avoid committing private voice recordings or sensitive data to a public repository.
